## 5. Prompt Set Used for Evaluation

The following prompts can be entered into all five platforms.

### Prompt 1: Technical Explanation

**Prompt:**

Explain the concept of Artificial Intelligence and Machine Learning in simple terms. Give three real-world applications of each and explain the difference between them.

**Expected Output:**

A clear explanation of Artificial Intelligence and Machine Learning, their differences, and examples of practical applications.

### Prompt 2: Text Summarization

**Prompt:**

Summarize the following paragraph in five bullet points:

"Generative Artificial Intelligence uses machine learning models to produce new content, including text, images, audio, and code. These systems learn patterns from training data and use them to generate responses based on user prompts. Large Language Models are widely used for text generation, summarization, translation, and question answering. Although these systems can improve productivity, their outputs may contain errors or bias. Therefore, users should verify important information before relying on AI-generated content."

**Expected Output:**

Five concise bullet points covering the main ideas without changing the meaning of the paragraph.

### Prompt 3: Programming Assistance

**Prompt:**

Write a simple Python program to check whether a number is even or odd. Explain the program line by line and show the output for the input 7.

**Expected Output:**

A correct Python program, a simple explanation, and the output showing that 7 is odd.
